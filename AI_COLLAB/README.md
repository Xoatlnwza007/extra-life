# AI Collaboration Message Board

This folder is a historical/supporting handoff channel. The authoritative project plan and current operating instructions are in the root `PROJECT_STATE.md` on `main`.

## Start here
1. Read `PROJECT_STATE.md` on `main` first. It overrides any older instruction in this folder.
2. Read `START_HERE.md`, then `PROTOCOL.md` and the latest task/message entries if useful.
3. Inspect the live GitHub refs and current `main` HEAD before coding.
4. Implement the next task from the root roadmap. ChatGPT is the sole engineering owner and is authorized to work directly on `main`.
5. Update `PROJECT_STATE.md` on `main` after meaningful work. Keep this board synchronized only when collaboration notes are useful.

## Current ownership
- **ChatGPT:** sole engineering owner for architecture, gameplay, adapters, combat/progression, NPC/crew simulation, save compatibility, UI, mobile/tablet UX, tests, integration, and technical documentation.
- **Narrative research/content:** optional input from other assistants. It is not an approval gate or dependency. Verify canon-sensitive claims and label original/sandbox content clearly.
- **Repository owner:** product direction and final release decisions. The owner has explicitly authorized direct changes to `main`.

## Important
- This board is not an automatic agent-to-agent connection.
- Do not store secrets, tokens, credentials, or personal data here.
- Historical task entries and old branch/PR instructions do not override `PROJECT_STATE.md`.
- Preserve prior messages; append new dated notes rather than erasing history.
